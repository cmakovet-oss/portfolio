Overview

Beyond Visual Effects

Personal Unity scene — designed and built by me — to show real-time VFX in a game engine: shaders, particles, 3D, animation, and gameplay hookup. This is portfolio work, not a shipped Unity title and not Snap production.

Environment

Terrain & World Building

The environment was built with Unity Terrain, while the main environment elements were created in Blender. Waterfalls, water, trees, grass, rocks, and the background mountains — all of these assets were exported from Blender and integrated into the scene.

VFX & Shaders

Procedural Effects Pipeline

The project includes around 20–30 different shaders and effects. Attack visual effects were built using particles, custom shaders, and particle shapes that are closely integrated with the shader pipeline. Water and waterfalls are implemented entirely in Shader Graph, with fully procedural animation. Tree sway animation is procedural as well.

Animation

Character & Enemy Motion

The main character animation was sourced from Mixamo and combined in Unity. Simple enemy animations were created in Blender and also consist of several states. In total, the project includes up to 20 character and enemy animations.

Materials & Textures

Procedural Surface Creation

Most of the main materials were created in Material Maker, using procedural workflows to build albedo, normal, and surface detail maps for environment assets throughout the scene.

C# & Coding

Gameplay Logic

The demonstration scene also includes gameplay logic for player control, attacks, and all core systems required to run the game.
